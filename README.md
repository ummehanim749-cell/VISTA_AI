# VISTA AI – NEMESIS-X

### Understanding Events That Have Never Been Seen Before

## About the Project
VISTA AI is an intelligent video analysis system designed to identify unusual and significant events in video sequences using AI.

## Key Features
- Object Detection
- Object Tracking
- Event Detection
- Temporal Analysis
- Anomaly Detection
- AI-Based Question Answering

## Technologies Used
- Python
- YOLO
- OpenCV
- Gradio
- JavaScript
- HTML & CSS

## Project Structure
- frontend/
- temporal_memory/
- app.py
- event_engine.py
- events.json
- media_processor.py
- question_answer.py
- tracking_data.json

## How to Run
1. Clone the repository.
2. Install the required dependencies.
3. Run the application using Python.
4. Upload a video and analyze events.
